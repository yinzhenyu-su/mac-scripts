## Context

macOS 对「可移除宗卷」的访问授权由 TCC 管理，且是懒加载的：应用第一次真正读取卷内容时，系统才弹出「“智能退出.app”想访问可移除宗卷上的文件」。现有实现直到定时任务到点调用 `diskutil eject` 时才第一次访问卷，授权框会在无人值守时出现，任务因此卡住。

实测确认：

- 在 `tccutil reset SystemPolicyRemovableVolumes fun.bgm.neatquit` 后，打开面板不会弹窗；对卷根目录执行 `contentsOfDirectory` 会立即弹出上述对话框。
- 选择「允许」后，规则正常创建；选择「不允许」后，读取抛错，可以据此阻止创建。
- `DiskArbitration` 的 unmount/eject 对 DMG 不能可靠 detach（实测 eject 回调成功但卷仍挂载），因此不切换到 DA 来规避授权。

## Goals / Non-Goals

**Goals:**

- 把可移除宗卷授权提前到用户创建规则或点击「立即弹出」的时刻。
- 授权失败时给出明确原因与设置入口，不留下一条到点必然失败的规则。
- 不新增 entitlement、后台 helper 或额外权限。

**Non-Goals:**

- 不改变弹出实现（仍使用 `diskutil eject`，不强制）。
- 不对升级前已存在的规则做追溯授权；它们首次到点仍可能弹窗。
- 不申请「完全磁盘访问权限」；当前场景只需要可移除宗卷授权。

## Decisions

### 1. 用卷根目录读取触发授权

`FileManager.default.contentsOfDirectory(atPath:)` 是能稳定触发可移除宗卷授权的无害操作。它只读目录元数据，不修改磁盘，也不会因为卷里有大文件而变慢。

备选方案：

- `fileExists` / `URLResourceValues`：实测不触发授权，否决。
- 直接调用 `diskutil` 预检：会真的卸载/弹出，破坏性太强，否决。
- 申请 Full Disk Access：权限过重，且无法用代码请求，否决。

### 2. 授权时机放在「开始」与「立即弹出」，不放在打开面板

面板打开时会对每块磁盘预检，用户还没决定操作哪块盘就被连续弹窗，体验差。放在提交动作前，用户知道这次授权是为哪块盘、哪个任务。

### 3. 拒绝后不创建规则，保持面板打开

读取失败时：

- 不调用 `scheduler.add`，避免留下到点必然失败的规则。
- 保持面板打开，用户去系统设置授权后可以直接重试。
- 弹出 `NSAlert`：说明需要访问该磁盘，提供「打开系统设置」与「取消」。
- 设置入口使用 `x-apple.systempreferences:com.apple.preference.security?Privacy_RemovableVolumes`；即使锚点失效，也会落到隐私与安全性页面。

### 4. 不做追溯授权

旧规则的数据结构不变。升级后第一次到点仍可能弹授权，此时用户允许即可完成本次弹出；想彻底避免，可以重新创建一次规则。发版说明里写清这一点。

### 5. 首次使用先解释，再触发系统授权

系统授权框只写「想访问可移除宗卷上的文件」，不解释为什么。第一次创建时先弹应用内说明：

- 说明这是为了到点自动弹出，下一步系统会请求「可移除宗卷」权限，请选择「允许」。
- 用户点「继续」后才读取卷根目录，触发系统授权。
- 用户点「取消」时既不发系统请求，也不创建规则。
- 用 `diskAccess.explained` 记住已经说明过，后续创建不再重复；如果用户之后在系统设置里撤销了授权，读取会失败并走拒绝提示。

## Risks / Trade-offs

- **[首次创建多一次系统弹窗]** → 这是把到点弹窗提前，总次数不变；文案与设置入口让用户知道原因。
- **[用户永久拒绝后不再弹窗]** → 读取持续失败，规则无法创建；提示里的「打开系统设置」是恢复路径。
- **[卷根目录很大]** → 只读一层目录元数据，通常毫秒级；不递归。
- **[`diskutil` 与 App 的 TCC 责任进程不一致]** → 若授权后到点仍失败，现有「未弹出」状态与重试入口兜底；需要在真实可移除磁盘上验证一次。
- **[旧规则到点弹窗]** → 升级说明要求重新创建一次规则，或在弹窗时允许。

## Migration Plan

1. 代码与文案随 1.6.1 发布；数据结构不变。
2. 升级说明增加「重新创建一次磁盘弹出任务以提前完成授权」。
3. 手工验证：`tccutil reset` → 创建规则 → 允许；再次创建 → 不弹窗；拒绝 → 不创建且提示。
