## What's New

- Disk eject rules now explain why access is needed, then request Removable Volumes access when you create them, so macOS does not interrupt the scheduled eject with a permission dialog
- Cancelling the in-app explanation neither triggers the system prompt nor creates the rule
- If you deny access, the rule is not created and Neat Quit points you to System Settings → Privacy & Security → Files and Folders
- Eject Now also checks access before ejecting
- Once granted, creating another rule for the same disk does not ask again
- Fixed a false "Didn't Eject" report when the disk was actually ejected: a lingering device node is no longer treated as failure
- Unfinished tasks are removed automatically after the disk is unplugged or the app quits, instead of staying in the status line

## Upgrade Notes

- Click "Install Update"; your app rules, license and scheduled tasks are unaffected
- Rules created before this update are not retroactively authorized. The first scheduled eject may still show the system prompt; recreate the rule once to grant access up front
- Full Disk Access is not required; only the Removable Volumes permission shown by macOS
