## What's New

- Added Quit Apps Later: set a countdown and Neat Quit quits the app you picked when it ends
- Targets can only be apps that are currently running, and the countdown starts the moment you set it
- Quit Apps Later ignores the Application Rules exclusion/only lists and acts on schedule, even if the app is in the exclusion list
- Only a normal quit request is sent, never a forced termination; if unsaved documents block it, the row shows "Didn't Quit" and can be retried manually
- Added Eject Disks Later: set a countdown for an external disk and it is unmounted and ejected when it ends
- Disks are grouped by physical device: a USB stick with several partitions still takes a single row, named after its main volume
- Ejection goes through the system `diskutil eject` and is never forced; a disk in use shows "Didn't Eject" and can be retried
- The countdown refreshes only while the menu is open; no new always-on timers
- The menu is regrouped by purpose: Status, Global, Assisted Quit, Quit Apps Later, Eject Disks Later, App Commands

## Behavior Changes

- "Enable Neat Quit" is now a true global switch: turning it off disables window-close quitting and both kinds of scheduled tasks
- If tasks are pending when you turn it off, a confirmation appears first and cancels them after you confirm
- New scheduled tasks cannot be created while the switch is off; configuration entries such as "⌘W Neat Quit" and "App Rules" remain available

## Upgrade Notes

- Click "Install Update"; your existing app rules and license are unaffected
- App quit timers you set earlier are migrated automatically on first launch, keeping their names and remaining time
- No scheduled tasks exist right after upgrading, so turning the switch off behaves the same as before
- Both scheduling features are Pro and available during the trial. Trial expiry does not delete existing timers or block them from running
- If the Mac sleeps through a deadline and wakes more than 5 minutes later, that task is dropped rather than run late
