## 更新内容

- 新增 Neat Quit Pro：一次买断（$4.99）解锁「⌘W 智能退出」与例外应用列表
- 免费版继续提供红色关闭按钮智能退出、登录时启动和菜单栏开关
- 新用户首次启动自动获得 7 天全功能试用，无需信用卡
- 新增「许可证」窗口：查看激活状态与已用设备数、刷新状态、移除授权
- 菜单直接标注哪些功能属于 Pro，试用剩余天数一目了然

## 升级说明

- 1.3.6 及更早版本中用过 ⌘W、例外列表或主开关的用户，升级后自动保留 Pro，无需重新购买
- 从 1.3.5 及更早版本升级仍需手动安装一次（Bundle ID 已变更）
- 购买后许可证密钥会显示在订单页并发送到邮箱；在菜单栏打开「许可证…」输入即可激活
- 每个许可证最多激活 3 台 Mac；换机时请先在旧设备点「移除授权」
