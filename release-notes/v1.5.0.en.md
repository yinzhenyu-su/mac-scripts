## What's New

- Renamed "Exception Apps" to "App Rules"; the menu entry now matches
- Added a search field to filter rules by app name or bundle ID, with one-click and Esc clearing
- Added "Only listed apps" mode: Neat Quit only quits apps in the list. It is mutually exclusive with "Quit all except listed" and takes effect immediately
- Each mode keeps its own list, so existing exception rules are unchanged after upgrading
- The "Add to Exceptions / Set to Auto Quit" menu item now follows the current mode
- The rules window resizes to fit its content, fixing the clipped bottom buttons after adding search
- Fixed Pro users still seeing a "(Pro)" suffix in the menu
- Reduced idle wakeups: permission polling is now every 2 seconds, and input monitoring checks are skipped when ⌘W is disabled

## Upgrade Notes

- Click "Install Update"; no manual steps are required
- After upgrading, the default is still "Quit all except listed", and your existing exception list and behavior are unchanged
- "Only listed apps" starts with an empty list; add the apps you want to auto-quit manually. Switching modes does not quit any currently open apps
- App Rules is a Pro feature; activated licenses and trial status are unaffected
