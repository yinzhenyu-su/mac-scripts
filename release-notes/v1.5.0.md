## 更新内容

- 「例外应用」窗口升级为「应用规则」，菜单入口同步改名
- 新增搜索框，可按应用名称或 Bundle ID 快速筛选规则，支持一键清空和 Esc 清空
- 新增「仅包含模式」：只对列表中的 App 智能退出；与「排除模式」互斥，切换后立即生效
- 两种模式各自保存列表，升级不会改变现有例外规则
- 菜单中的「加入例外 / 设为自动退出」会跟随当前模式变化
- 规则窗口高度按内容自适应，修复新增搜索框后底部按钮被裁切的问题
- 修复 Pro 用户菜单中仍显示「（Pro）」后缀的问题
- 降低空闲唤醒：权限轮询调整为 2 秒，并跳过未启用 ⌘W 时的输入监控检查

## 升级说明

- 直接点「安装更新」即可，无需手动操作
- 升级后默认仍是「排除模式」，原有例外列表和行为保持不变
- 首次切换到「仅包含模式」时列表为空，需要手动添加要自动退出的 App；切换模式本身不会退出任何已打开的 App
- 「应用规则」属于 Pro 功能，已激活的许可证和试用状态不受影响
