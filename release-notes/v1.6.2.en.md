## What's New

- Fixed app rules being lost when upgrading from 1.3.5 or earlier: on launch Neat Quit now restores the exception list, rule mode and switches from the old bundle-ID preference domain (`com.yinzhenyu.smartclose`), and restores the legacy Pro entitlement
- Added common background-resident apps to the built-in default list — chat & collaboration, cloud sync, input methods, menu bar utilities, proxy & VPN — for a total of 58 default rules
- Apps that are not installed now show readable localized names in the App Rules list instead of raw bundle IDs
- Added "Reset to Defaults" to the App Rules window: after confirmation, the exclusion list is restored to the built-in default list, while the "only listed" (blacklist) list is cleared
- If stored rules cannot be decoded, the original data is backed up before falling back to the default list instead of being dropped silently
- Rule changes are now synced between multiple instances of the app so they cannot overwrite each other
- App updates no longer modify lists you have edited; only lists that were never edited and still match an old auto-seeded default are upgraded once to the new default list

## Upgrade Notes

- Click "Install Update"; your app rules, license and scheduled tasks are unaffected
- Your configured exception list is not reset by the update; only lists that were never edited and still match an old auto-seeded default are upgraded once to the new 58-rule list
- Users upgrading from 1.3.5 or earlier automatically get their old exception rules and legacy Pro entitlement back if the old preferences are still on disk
- To restore the built-in default rules, use "Reset to Defaults" in the App Rules window
